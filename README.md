# ⚡ PULSE Electronics

**Power That Moves With You.**

A sleek, fully responsive e-commerce storefront for laptops, phones, accessories, and gaming gear — built with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools, just fast and clean front-end code.

---

## ✨ Features

- **Dynamic Product Catalog** — products rendered live via JavaScript with category tabs (Laptops, Phones, Accessories, Gaming)
- **Search & Sort** — filter products by name, sort by price (low/high) or alphabetically
- **Shopping Cart** — add to cart, adjust quantities, choose delivery method (Standard / Express), live subtotal & total
- **Authentication Modal** — Login / Sign Up tabs with a demo account for quick testing
- **Product Details Modal** — quick-view popup for each product
- **Deals Countdown Timer** — live countdown for limited-time offers
- **Dark Mode Toggle** — switch between light and dark themes
- **Newsletter & Contact Forms** — with front-end validation and toast notifications
- **Fully Responsive** — mobile-friendly navigation with a hamburger menu
- **Toast Notifications** — for cart actions, form submissions, and auth events

## 🚀 Getting Started

### Prerequisites
No build tools or dependencies required — just a web browser.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/ali-shker/PulseElectronics.git
   ```
2. Navigate into the project folder
   ```bash
   cd PulseElectronics
   ```
3. Open `index.html` in your browser, or serve it locally:
   ```bash
   npx serve .
   ```
